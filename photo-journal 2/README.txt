关于你，随手存下的一些瞬间

打开方法
1. 先解压整个压缩包。
2. 打开 photo-journal 文件夹，双击 index.html。
3. 用 Chrome、Safari 或 Edge 浏览。无需安装，不用联网。
4. 请保持 index.html、styles.css、script.js 和 photos 文件夹的相对位置不变。

观看
点击“那就从这里开始吧 →”，或者直接向下滚动。
桌面上的两组四拍分镜由滚动位置控制，可以随时向前或向后。
手机和平板使用自然竖排布局。
结尾可以“再看一遍”，右下角还有一颗可以点击的星星。
星星卡片可再次点击星星、点击关闭，或按 Esc 关闭。
所有按钮支持键盘操作；系统开启“减少动态效果”后，页面自动取消延时和运动。

隐私和照片
本版本只在本地运行，未上传、发布或改动照片。
没有联网资源、音乐、网络字体、账号、数据收集或存储依赖。
19 张照片与 PRD 包内原图逐字节一致，原生边框和文字均保留。

检查范围
已检查 Chrome 的桌面和手机模拟视口、file:// 离线运行、开始、重看、彩蛋、减少动态效果和无 JavaScript 阅读。
桌面尺寸：1440×900、1366×768、1920×1080。
手机模拟尺寸：390×844、360×800。未进行真实 iOS / Android 设备测试。
